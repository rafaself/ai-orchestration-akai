# AI Orchestration Akai

A Codex-first guidance kit for substantial or risky work that benefits from planning, implementation, and independent review.

This repository provides a workflow skill and example role profiles. It does not launch agents or enforce phase transitions. The task thread is the working record; the target project remains responsible for security, approvals, validation, and integration rules.

## Start here

Read [the workflow skill](.agents/skills/plan-execute-review/SKILL.md) and [project-adaptation guidance](.agents/skills/plan-execute-review/references/adapting-to-a-project.md). Use the full workflow when it improves control; keep small, low-risk tasks lightweight.

## Contents

- `.agents/skills/plan-execute-review/` — coordinator workflow and project-adaptation guidance.
- `.codex/agents/` — example planner, executor, and reviewer profiles to adapt.

The role profiles are examples, not permissions. Adapt their sandbox settings and instructions to the target project before use.
